            • 调整幅度：在无痛范围内训练，如箱式深蹲、缩短动作行程

            设备自检

            检查这台设备的浏览器对 FreeBody 所需功能的支持情况。检测只在本机进行，报告不含任何记录内容，可复制后贴到 issue。

              真机测试清单

              自检只能覆盖浏览器能力。下面几项需要人在真机上看一眼，完整清单见仓库 docs/device-test.md。

              1. 底部导航贴住屏幕底边，下面没有空白条；最后一张卡片能完整滚出导航上方。
              2. 页头 logo 不被状态栏或刘海遮挡；日期栏与卡片左右对齐。
              3. 今天页点「补剂」打卡，刷新后仍在。
              4. 打开一个 #import= 导入链接，预览后确认导入，再撤销。
              5. 开启飞行模式后重新打开，仍可使用。
              6. 「我的 › 数据备份」导出 JSON，文件能在「文件」App 中找到。

              常用

              个人配置

              身高用于计算 BMI；伤处标记是训练记录中「伤处不适」的显示名。
              拍照识别 · 模型 API
              识别时，照片会发送给你选择的服务商处理，并受其隐私政策约束；FreeBody 不保存照片。API Key 只存在本机浏览器，导出备份默认不含 Key。

              示例配置（可选）

              合并示例的伤病、受限动作、康复清单配置，不含记录数据。

                可加载与 examples/ 同格式的本地 JSON（如个人配置），只合并配置与清单。

                食物库

                格式见 docs/food-database.md。欢迎向 data/foods.json 贡献条目。

                批量导入 CSV
