# 批量导入 CSV

入口：我的 ›「批量导入 CSV」。程序根据**表头**自动识别类型（按下表顺序匹配第一个满足"必需列"的类型），导入前会弹窗确认。可在同一位置下载各类型的空模板（UTF-8 带 BOM，Excel 可直接打开）。

| 类型 | 必需列 | 全部列 | 重复日期处理 |
|---|---|---|---|
| 力量训练 | date, exercise, sets, reps | weight, rpe, note | 追加 |
| 饮食 | date, food | meal, kcal, p, c, f（kcal 留空按 4P+4C+9F） | 追加 |
| 化验 | date, name, value | unit, lo, hi, note | 追加 |
| 睡眠 | date, bed, wake | q, note（时长自动计算） | 覆盖当日 |
| 游泳 | date, stroke, dist | time（mm:ss）, swolf, note | 追加 |
| 爬楼 | date, min | floors, hr | 追加 |
| 身体指标 | date + 至少一列 weight/bf/waist/rhr | | 覆盖当日 |

## 中文表头

可直接使用中文列名：日期、餐次、食物、热量、蛋白质/蛋白、碳水、脂肪、动作、组数、次数、重量、备注、体重、体脂、腰围、静息心率、入睡、起床、质量、指标、数值、单位、下限、上限、时长、层数、心率、泳姿、距离、用时。

## 格式要求

- 日期：`YYYY-MM-DD`（也接受 `YYYY/M/D`、`YYYY.M.D`）；时间：`HH:MM`。
- 含逗号的字段请用英文双引号包裹，如 `"划船, 坐姿"`。
- 日期或必需数值无效的行会被跳过，并在结果中提示数量。

## 示例

```csv
日期,动作,组数,次数,重量,RPE
2026-10-01,杠铃卧推,3,8,50,7
2026-10-01,高位下拉,3,10,45,
```

> 导入的文件可能含个人健康数据，请勿提交到仓库。
