# 真机测试清单

[English](device-test.en.md)

FreeBody 的自动化测试都在 Linux 上的浏览器模拟环境里运行（Chromium、WebKit），**不能代替真机**。iOS 主屏幕应用的布局、存储隔离、读屏软件这类问题，只有在真机上才看得到。本清单约 15 分钟可以跑完，结果请用 [真机测试报告](https://github.com/leenlbma/freebody/issues/new?template=device_report.yml) 提交，全部通过也请提交。

**不要用自己的真实记录测试。** 先在「我的 › 帮助与自检」点「试用演示数据」，演示数据只在当前页面中，不会写入或覆盖你的数据。需要测试保存与刷新时，用一个没有记录过数据的浏览器或主屏幕图标。

## 0. 设备自检

1. 打开 <https://leenlbma.github.io/freebody/>，进入「我的 › 帮助与自检 › 设备自检」。
2. 点「复制报告」，粘贴到测试报告里。报告只含浏览器能力与屏幕尺寸，不含记录内容。
3. 有「异常」项时，先记下，再继续后面的步骤。

## 1. 布局（每种打开方式各看一次：浏览器标签页、添加到主屏幕）

| # | 检查 | 通过标准 |
|---|---|---|
| 1.1 | 底部导航 | 贴住屏幕底边，下面没有空白或黑条；带 Home 指示条的机型，按钮在指示条上方 |
| 1.2 | 页头 | logo 与主题按钮不被状态栏、刘海、灵动岛遮挡 |
| 1.3 | 日期栏 | 左右边缘与下方卡片对齐 |
| 1.4 | 滚到底 | 最后一张卡片能完整滚出导航上方 |
| 1.5 | 横屏 | 改为左侧导航，内容不被刘海遮挡 |
| 1.6 | 导入预览 | 底部「确认导入」栏在导航上方，不遮挡最后一条 |
| 1.7 | 深色模式 | 系统切到深色后，页面跟随；没有看不清的文字 |
| 1.8 | 大字体 | 系统字体调到最大一档，按钮文字不被截断、不重叠 |

> iOS 主屏幕应用如果底部出现空白条：删除主屏幕图标，在 Safari 中重新「添加到主屏幕」后再看一次，并在报告里写明重新添加前后的差别。

| # | 操作 | 通过标准 |
|---|---|---|
| 2.1 | 今天页「补剂」全部打卡，关闭页面再打开 | 打卡仍在 |
| 2.2 | 饮食 › 添加食物，搜索「米饭」加入午餐 | 今天页热量变化 |
| 2.3 | 训练 › 开始训练，记一组后完成 | 训练记录出现，组间计时正常 |
| 2.4 | 数据 › 睡眠，填入就寝与起床时间保存 | 今天页准备度出现 |
| 2.5 | 切到后台 10 分钟再回来 | 数据与当前页面都在 |

## 4. 离线

1. 在线打开一次，等待几秒。
2. 开启飞行模式，彻底关闭再重新打开。
3. 通过标准：页面正常显示，可以记录；「设备自检」中 Service Worker 显示「已接管」。

## 5. 备份与存储

| # | 操作 | 通过标准 |
|---|---|---|
| 5.1 | 我的 › 数据备份 › 导出 JSON | 文件能在「文件」App / 下载目录中找到 |
| 5.2 | 用另一个空白环境「导入 JSON」 | 记录完整恢复 |
| 5.3 | 查看「持久存储」状态 | 记录显示的是「已开启」还是「未开启」 |
| 5.4 | iOS：Safari 与主屏幕应用各打开一次 | 两边数据互不相通（这是系统行为，用于确认文档说明正确） |

## 6. 读屏与键盘

| # | 操作 | 通过标准 |
|---|---|---|
| 6.1 | 开启 VoiceOver（iOS）或 TalkBack（Android），左右滑动浏览今天页 | 能读出导航、卡片标题、按钮名称，没有只读「按钮」的无名按钮 |
| 6.2 | 进入 数据 › 身体，聚焦体重图 | 读出图表摘要（最新值与变化）；展开「数据表」能逐行读出 |
| 6.3 | 切换底部导航 | 读出「已打开 …」 |
| 6.4 | 电脑上只用键盘：Tab、Enter、Esc、数字键 1–4 | 每个可点元素都有焦点框，能完成一次饮食记录 |
| 6.5 | 系统开启「减弱动态效果」 | 图表与页面切换没有动画 |
